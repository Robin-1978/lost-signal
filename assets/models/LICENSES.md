# Model asset license registry

The root `LICENSE` and `NOTICE` apply to project-authored model assets unless a
more specific entry in this file or `manifest.json` says otherwise.

`LicenseRef-LostSignal-Project` identifies assets generated from source tools
in this repository. Their distribution follows the project's Apache-2.0
release terms. `CC0-1.0` entries retain their explicit public-domain grant.

The former `NOASSERTION` entries were the legacy-main migration set. The D4
audit traced all 39 files to commits authored by the project contributor in
this repository and found no external source artifact or third-party import
record in git history. They are therefore recorded as `Apache-2.0` in the
manifest, with their original `legacy-main:*` source artifact retained for
traceability. A future external provenance discovery must replace that entry
with the verified upstream license before redistribution.
