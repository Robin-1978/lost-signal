# Model asset license registry

`LicenseRef-LostSignal-Project` identifies assets generated from source tools
in this repository. Their distribution follows the project's release terms.

`NOASSERTION` marks assets migrated from the historical `main` branch whose
license metadata was absent. This is intentional provenance debt: those files
must receive a verified license before an external asset pack is published.
The manifest keeps them visible instead of inventing a license claim.
