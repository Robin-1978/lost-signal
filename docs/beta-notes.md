# 内测 Beta 说明（无真车版，2026-10）

## 一句话
仿真侧全绿、零卡死、客户端编过；没真机看画面、没人类玩过。
能开内测，不能叫正式版，更不许提 sim-to-real。

## 上线标准（游戏版，无真车 track 专用）
1. 全套件绿：44 CTest＋24 pytest＋validator（含 strings 双向门）。
2. 零卡死：schema 强制每关 `time_limit_s`＋仿真时钟无条件推进，
   任何对局 ≤9000 步必以成功/失败/超时其一结束（证毕，非口号）。
3. 客户端编译通过（本机编过，跑不起来看——无 X，CI 补 smoke 截图）。
4. 难度诚实（3 种子实测，非拍脑袋）：
   - 硬地形＋默认（白板）装配超时是设计：scrub_climb／sand_track／
     long_track 默认 0/3（150s 到点），推荐 3/3——教玩家逛车库。
   - 遭遇关推荐配置有相位彩票：lost／echo／hold／watch 推荐 1~2/3，
     hold 默认 30 种子 14/30。标“高难”，不修数（调内容凑数是红线）。
   - 其余关推荐 3/3。

## 人类试玩协议（8 人，机器到了就跑）
1. 每人打通第一章＋town 任意一单，记录卡关点（关／装配／时长）。
2. 高难关必问：难得合理还是难得想骂？（区分设计与 bug）
3. 车库：不看说明，能否自己配出过硬地形的车？
4. 悬赏板：单子看得懂吗？rep 有赚头感吗？
5. 画面：2D/3D 各截 3 张，穿帮直接贴图。
通过线：无人卡死（超时不算卡死，算失败）；80% 能自己配出硬地形车。
